# Anusandhan Setu

A premium product prototype connecting verified academic research with funded industry and government problem statements.

## Core workflows

- Discovery
- Verified research asset
- Funded problem brief
- Evidence-led match room

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/` and can be deployed directly on Vercel.
